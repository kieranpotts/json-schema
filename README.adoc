== Testing

Tests can be run in a containerized environment. The only requirement is that you have *Docker* installed on your system. All other dependencies will be installed in the container.

First, make sure the `run` script, in the root directory of this repository, is executable:

----
chmod +x run
----

To run the tests, run the following command from the root directory of this repository:

----
./run test
----
