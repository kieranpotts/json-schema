= Date (year and month only)

****
Schema: link:../src/date-year-month.schema.json[date-year-month.schema.json]
****

This schema defines a seven-character string representing a year and month in the https://www.iso.org/iso-8601-date-and-time-format.html[ISO 8601] YYYY-MM date format. It is timezone independent.

== Valid examples

* `2023-10`
