# Date (year and month only)

**Schema:** [date-year-month.schema.json](../src/date-year-month.schema.json)

This schema defines a seven-character string representing a year and month in the [ISO 8601](https://www.iso.org/iso-8601-date-and-time-format.html) YYYY-MM date format. It is timezone independent.

## Valid examples

- `2023-10`
