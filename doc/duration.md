# Duration

**Schema:** [duration.schema.json](../src/duration.schema.json)

This schema defines a duration expressed in terms of years, months, weeks, days, hours, minutes, and seconds, and formatted according to the [ISO 8601](https://www.iso.org/iso-8601-date-and-time-format.html) standard (`PyYmMdDThHmMsS`).

## Valid examples

- `P1Y2M3DT4H5M6S`
