= Email address

****
Schema: link:../src/email-address.schema.json[email-address.schema.json]
****

This schema defines a valid internationalized email address, as defined by https://datatracker.ietf.org/doc/html/rfc5322[IETF RFC 5322], https://datatracker.ietf.org/doc/html/rfc6530[RFC 6530], and other standards.

It is practically impossible to define a single regular expression that can validate all possible international email address formats. Therefore, this pattern verifies only that the string contains an unquoted @ sign and is no longer than 254 characters.

[NOTE]
======
Due to RFC 5321, an email address can be up to 254 character long – even though up to 64 characters are allowed before the @ sign, and 255 characters are allowed after the @ sign.
======

== Valid examples

* `example@example.com`
