# JSON Web Encryption (JWE) token

**Schema:** [json-web-encryption-token.schema.json](../src/json-web-encryption-token.schema.json)

This schema defines a JWE token, as specified in [IETF RFC 7516](https://www.rfc-editor.org/rfc/rfc7516.txt). JWE tokens are used to encrypt data.
