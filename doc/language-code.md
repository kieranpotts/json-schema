# Language code

**Schema:** [language-code.schema.json](../src/language-code.schema.json)

This schema defines a language tag, as specified in [BCP-47](https://www.rfc-editor.org/info/bcp47), which is composed of an ISO-639 alpha-2 language code, a ISO-15924 script tag, and a ISO-3166 alpha-2 country code.

## Valid examples

- `en`
