# Monetary amount

**Schema:** [monetary-amount.schema.json](../src/monetary-amount.schema.json)

This schema defines a quantity of money, expressed in a currency such as USD ($), GBP (£), EUR (€), or JPY (¥). This data type is typically used to represent a financial value in transactions, accounting, budgeting, or economic analysis.

## Valid examples

```json
{
  value: '100.50',
  currency_code: 'USD'
}
```
