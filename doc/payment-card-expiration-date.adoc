= Payment card expiration date

****
Schema: link:../src/payment-card-expiration-date.schema.json[payment-card-expiration-date.schema.json]
****

This schema defines a date in the format MM/YY or MM/YYYY. This format is typically used to represent payment card expiration dates. The value is timezone independent.

== Valid examples

* `"12/25"`
* `"12/2025"`

== Invalid examples

* `"13/25"`
* `"13/2025"`
