= Province

****
Schema: link:../src/province.schema.json[province.schema.json]
****

This schema defines a state or province code, based on https://en.wikipedia.org/wiki/ISO_3166-2[ISO 3166-2] definitions.

== Valid examples

[source,json]
----
{
  province_code: "US-CA",
  country_code: "US",
  local_name: "California",
  latin_name: "California",
  abbreviation: "CA"
}
----
