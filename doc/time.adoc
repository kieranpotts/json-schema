= Time (no date)

****
Schema: link:../src/time.schema.json[time.schema.json]
****

This schema defines a time value, as specified in https://datatracker.ietf.org/doc/html/rfc3339#section-5.6[IETF RFC 3339 section 5.6], but with a practical limit on the length of the fractional seconds part.

== Valid examples

* `14:30:45Z`

== Invalid examples

* `25:61`
